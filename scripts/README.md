# CamboAI Automation Scripts

- Start backend (full): `./Start-Backend-Full.ps1`

- Frontend build (web-advanced): `./Build-Frontend.ps1`
- Frontend preview: `./Preview-Frontend.ps1`
- Load test (basic): `./Load-Test-Backend.ps1`
