# Backtesting and Journaling

## Backtesting
- Define rules first; no curve fitting
- Use walk-forward and out-of-sample data
- Track metrics: Win rate, Avg R, Max DD, Expectancy, Sharpe

## Paper Trade / Forward Test
- Trade small with the same rules to validate execution

## Journaling
- Template: Date, Ticker, Setup, Entry/Stop/Target, Risk R, Exit, Result R, Notes
- Weekly review: tag errors (late entry, stop too tight), actions to fix
