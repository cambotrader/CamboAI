# Mobile App Assets

Place your app icons and splash screens here:

## Required Files:
- `icon.png` (1024x1024) - App icon
- `adaptive-icon.png` (1024x1024) - Android adaptive icon
- `splash.png` (1284x2778) - Splash screen
- `favicon.png` (48x48) - Web favicon

## Free Icon Resources:
- **Canva** (Free design tool)
- **GIMP** (Free image editor)
- **Figma** (Free design tool)
- **Unsplash** (Free stock photos)
- **Flaticon** (Free icons with attribution)

## Quick Icon Creation:
1. Use Canva's app icon template
2. Add your logo/text
3. Export as PNG
4. Resize using online tools if needed

## Expo Icon Generator:
```bash
# Auto-generate all required sizes
npx expo install expo-app-icon-utils
npx expo-app-icon-utils generate
```
